# 辞書編集ガイド

このページは、`dicts/default.txt`（共通辞書）と文書別辞書（`*.dict.txt`）の編集手順をまとめたものです。

## 1. 辞書ファイルの場所

- 共通辞書: `dicts/default.txt`（リポジトリ直下の `dicts/` ディレクトリ）
- 文書別辞書: 各文書ごとの `*.dict.txt`
- 追加の共通辞書: `dicts/` ディレクトリ内の任意の `.txt` ファイル

## 2. フォーマット

タブ区切りテキストです。

```text
#英語	#日本語	#状態	#出現回数
Blaadesharp	《鋭刃》	0	3
Beffadle	《惑い》	0	2
```

- 1列目: 置換元（英語）
- 2列目: 置換先（日本語）
- 3列目: 状態（省略時は `0` 扱い）
- 4列目: 出現回数（抽出対象文書に応じて再計算）

## 3. 状態（3列目）の意味

- `0`: 大文字小文字を区別せず置換
- `1`: 大文字小文字が一致する場合のみ置換
- `2` 以上: 自動生成用の予約状態（ユーザーが `0` / `1` に戻すまで通常置換では無視）

## 4. 反映手順

辞書を編集しただけでは反映されません。次のいずれかを実行してください。

- `3.全対訳置換`
- `ページ対訳置換`

## 5. 辞書メンテナンス画面でできること

- 辞書の一覧表示と一括更新
- 同一語の訳比較
- 辞書エントリの自動翻訳
- 辞書間の転送

## 6. 運用のコツ

- 共通語は `dicts/default.txt`、文書固有語は文書別辞書に分ける
- 追加の共通辞書は `dicts/` ディレクトリ内に `.txt` ファイルとして配置できる
- 新規追加語はまず `状態=0` で運用し、必要な語だけ `1` にする
- 変更前に辞書ファイルをバックアップしておく
