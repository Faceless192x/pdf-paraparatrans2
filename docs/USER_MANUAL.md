# PDF ParaParaTrans 2 ユーザーマニュアル

このガイドは、PDF ParaParaTrans 2 を日常的に使う方向けのマニュアルです。

README より少し詳しく、画面の見方と操作の流れをまとめています。

## まず知っておきたいこと

- このアプリは、長い PDF や Web ページを**段落単位で整えながら翻訳する**ためのアプリです。
- まず自動翻訳でたたき台を作り、そのあと必要な段落だけ直す使い方に向いています。
- **無料で始めたいなら Ollama が便利**です。API 利用料がかからず、文章を外部に送らずに使えます。
- Google 翻訳 API や DeepL API を使う場合は、翻訳する文章が外部サービスに送られます。

## 画面の流れ

1. 一覧画面で PDF を追加する
2. PDF 名を開く
3. `1.抽出` で段落を取り出す
4. 必要に応じて `2.段落連結` と `3.全対訳置換` を行う
5. `4.全翻訳` またはページ翻訳で訳を作る
6. 各段落を編集して、仕上がったものを `確定` にする

## 各列の役割

### Html

元の PDF の文字情報です。

通常は見なくても作業できますが、抽出結果の確認に使うことがあります。

### 原文

PDF から取り出した元の文章です。

まずはこの列を見て、段落の切れ方や順番が大きく崩れていないか確認します。

### 連結文

切れていた段落をつないだ結果です。

文章が途中で途切れているときは、この列を見ながら調整します。

### 置換文

辞書を反映した、翻訳前の文章です。

翻訳エンジンには、この列の内容が送られます。用語をそろえたいときは特に重要です。

### Auto

自動翻訳の結果です。

たたき台として確認し、訳文にそのまま使えるかを見ます。

### 訳文

最終的に仕上げていく列です。

読みやすさや表現を整えるときは、この列を編集します。

### コメント

段落ごとのメモ欄です。

あとで見直したいこと、用語の候補、保留事項などを残せます。

## 編集ボックスの使い方

各段落の `...` を押すと、編集ボックスが開きます。

編集ボックスでは、次の操作ができます。

- **結合**: 前の段落とつなげるかを切り替える
- **種別**: 本文、見出し、header、footer などを選ぶ
- **同スタイルを一括更新**: 似た見た目の段落をまとめて直す
- **自動翻訳**: その段落だけ試しに翻訳する
- **ステータス変更**: 未翻訳 / 自動翻訳 / 下訳 / 確定
- **保存**: 編集内容を反映する

### ステータスの使い分け

- **未翻訳**: まだ手を付けていない段落
- **自動翻訳**: 自動翻訳をかけた段落
- **下訳**: まだ見直し途中の段落
- **確定**: 仕上がった段落

迷ったら、直し途中のものは `下訳`、完成したものは `確定` にしておくと管理しやすいです。

## おすすめの進め方

### まず全体を読みたいとき

1. `1.抽出`
2. `4.全翻訳`
3. 気になるところだけ直す

### 用語をそろえたいとき

1. 辞書に用語を入れる
2. `3.全対訳置換`
3. `4.全翻訳`
4. 訳文を整える

### 段落の切れ方が不自然なとき

1. `原文` と `連結文` を表示する
2. 必要な段落で結合を切り替える
3. `2.段落連結` を実行する
4. 直ったか確認する

## キーボードショートカット

このアプリは、キーボードで高速に編集しやすいのが大きな特徴です。

### まず覚えたいもの

- `↑ / ↓`: 段落移動
- `Shift + ↑ / ↓`: 選択しながら移動
- `Alt + ↑ / ↓`: 選択中の段落を上下に移動
- `Alt + 0〜9`: 種別変更
- `Alt + +` または `Alt + ;`: 結合の切り替え
- `Alt + /`: 今の段落だけ翻訳
- `Ctrl + Alt + /`: 今のページを翻訳
- `F2`: 編集ボックスの表示切り替え
- `Ctrl + S`: 保存
- `Ctrl + Shift + K`: KeyHUD の表示切り替え

### HotKey と KeyHUD

- **HotKey** ボタンを押すと、ショートカット一覧を表示できます。
- **KeyHUD** を表示すると、押したキーと説明をその場で確認できます。

ショートカットを少しずつ覚えると、マウス中心よりかなり速く作業できます。

## 困ったとき

### 画面が開かない

- `http://localhost:5077/` を直接開いてください。
- 別のアプリが同じポートを使っていないか確認してください。
- 必要なら `.env` の `PORT` を変えて再起動してください。

### 自動翻訳の前に用語を直したい

- 辞書を登録してから `3.全対訳置換` を実行してください。
- 翻訳前の最終確認には `置換文` 列を見るのがおすすめです。

### どの列を表示すればよいか迷う

まずは次の組み合わせがおすすめです。

- 構造調整中: `PDF / 原文 / 連結文`
- 翻訳前の確認: `PDF / 置換文 / Auto`
- 仕上げ中: `連結文 / Auto / 訳文 / コメント`
