# PDF ParaParaTrans 2 ヘルプ

このヘルプは、画面上の各ボタンや表示項目が何をするものかを、利用者向けにまとめたものです。

## 使い方の流れ

1. 一覧画面で PDF または URL ブックを追加します。
2. 詳細画面を開いて `1.抽出` を実行します。
3. 必要に応じて `2.段落連結` と `3.全対訳置換` を行います。
4. `4.全翻訳` またはページ翻訳でたたき台を作ります。
5. 各段落の編集ボックスで訳文やステータスを整えます。

## 列の見方

### Html
元の PDF から取れた文字情報です。普段は非表示でも問題ありません。

### 原文
抽出した元の文章です。段落の切れ方や順番の確認に使います。

### 連結文
切れていた段落をつないだ結果です。文章の流れを整えたいときに見ます。

### 置換文
辞書を反映した翻訳前の文章です。翻訳エンジンへ送る前の最終形です。

### Auto
自動翻訳の結果です。たたき台として確認します。

### 訳文
最終的に仕上げていく列です。手直ししたい場合はここを見ます。

### コメント
段落ごとのメモ欄です。保留事項や注意点を書いておけます。

## 編集ボックスの使い方

各段落の `...` ボタンを押すと編集ボックスが開きます。

- `結合`: 前の段落とつなげるかを切り替えます。
- `種別`: 本文、見出し、header、footer などを選びます。
- `同スタイルを一括更新`: 似た見た目の段落をまとめて整えます。
- `自動翻訳`: その段落だけ翻訳します。
- `未翻訳 / 自動翻訳 / 下訳 / 確定`: 作業状況を管理します。
- `保存`: 編集内容を反映します。

## キーボードショートカット

このアプリは、キーボードで高速に編集しやすいのが特徴です。

- `↑ / ↓`: 段落移動
- `Shift + ↑ / ↓`: 選択しながら移動
- `Alt + ↑ / ↓`: 選択中の段落を上下へ移動
- `Alt + 0〜9`: 種別変更
- `Alt + +` または `Alt + ;`: 結合の切り替え
- `Alt + /`: 今の段落だけ翻訳
- `Ctrl + Alt + /`: ページ翻訳
- `F2`: 編集ボックスの表示切り替え
- `Ctrl + Shift + K`: KeyHUD の表示切り替え

## ブックリストの更新

一覧画面を最新の状態に更新します。

新しい PDF を追加した直後や、別の画面から戻ったあとに使います。

## PDFのアップロード

PDF ファイルを一覧に追加します。

追加した PDF は一覧から開いて、そのまま翻訳作業を始められます。

## URLブックの追加

Web ページを翻訳対象として追加します。

PDF ではなく、Web サイトや記事を同じ流れで整理したいときに使います。

## ブックのフィルタリング

タイトルやファイル名で一覧を絞り込みます。

探したい文書が増えてきたときに便利です。

## 一覧画面に戻る

詳細画面から一覧画面へ戻ります。

## 表題と構造を保存

タイトルの変更や段落の並び替え、種別変更などを保存します。

作業の区切りごとに押しておくと安心です。

## ログを開く

処理ログを表示します。

抽出や翻訳の途中で何が起きているか確認したいときに使います。

## ショートカット入力の表示/非表示

KeyHUD の表示を切り替えます。

KeyHUD を表示すると、押したキーとその意味を画面上で確認できます。

## ホットキーマッパーを開く

ショートカットキーの一覧を開きます。

よく使うキーを覚えたいときに便利です。

## パラグラフの抽出

PDF や URL ブックから、作業単位になる段落を取り出します。

最初に押す基本操作です。PDF の作りによっては、段落の切れ方が完全ではないことがあります。

## 自動タグ付け

見出しや本文らしさを見て、段落の種別をまとめて付けます。

目次を作りやすくしたいときや、最初の整形を早く済ませたいときに使います。

## すべてのページで段落の連結

文書全体の `連結文` と `置換文` を作り直します。

途中で切れている文章を、翻訳しやすい形へ整えるための操作です。

## 辞書の翻訳

辞書候補を自動翻訳するための項目です。

通常の利用では表示されないことがあります。

## すべてのページを対訳置換

文書全体の `置換文` に辞書を反映します。

用語をそろえたいときは、翻訳前にこの操作を行うのがおすすめです。

## すべてのページを翻訳

文書全体の未翻訳段落をまとめて翻訳します。

訳のたたき台を一気に作りたいときに使います。

## 同一連結文の訳揃え

同じ `連結文` を持つ段落の訳を、文書全体でそろえます。

用語のゆれや重複をまとめて直したいときに便利です。

## ブックデータのリロード

現在の文書データを読み直して画面へ反映します。

隠し機能や一括処理のあとに、表示を最新化したいときに使います。

## HTMLのレンダリング

HTML 表示を再描画するための開発寄りボタンです。

通常の利用では使う場面は多くありません。

## データ入出力ダイアログ

出力や構造ファイル、辞書関連の操作をまとめて開く画面です。

ここから対訳 HTML、Markdown、テキスト、構造ファイルなどを扱えます。

## URL取得ルール

URL ブックで、どの範囲を本文として取り込むかを調整します。

サイトごとに取り込みやすさを整えたいときに使います。

## srcPanel本文のフォントサイズ変更

右側の本文表示の文字サイズを変更します。

長文を読みやすくしたいときに使います。

## 目次パネルの表示/非表示

目次パネルの表示を切り替えます。

見出しをたどりながら移動したいときは表示しておくと便利です。

## PDFパネルの表示/非表示

PDF パネルの表示を切り替えます。

原文 PDF を見比べながら作業したいときに使います。

## URLパネルの表示/非表示

URL プレビューの表示を切り替えます。

URL ブックを使っているときに、元ページを見ながら確認できます。

## ソースHTMLの表示/非表示

Html 列の表示を切り替えます。

通常は非表示でかまいません。

## 原文の表示/非表示

原文列の表示を切り替えます。

抽出結果の確認や段落のつながりを見るときに使います。

## 連結文の表示/非表示

連結文列の表示を切り替えます。

段落の結合結果を見ながら整えたいときに便利です。

## 置換文の表示/非表示

置換文列の表示を切り替えます。

辞書がどう反映されたかを確認したいときに使います。

## 自動翻訳の表示/非表示

Auto 列の表示を切り替えます。

機械翻訳のたたき台を見たいときに使います。

## 訳文の表示/非表示

訳文列の表示を切り替えます。

最終的に仕上げる訳を中心に見たいときに使います。

## コメントの表示/非表示

コメント列の表示を切り替えます。

メモを見ながら作業したいときに便利です。

## 前のページ

前のページへ移動します。

## 次のページ

次のページへ移動します。

## URLページを追加

URL ブックに新しいページを追加します。

同じサイト内の記事を少しずつ足したいときに使います。

## サイト内クロール

同じサイト内のリンクをたどって、URL ブックへ候補ページを取り込みます。

一括でページを集めたいときに便利です。

## ページ対訳置換

今見ているページだけに辞書を反映します。

ページ単位で様子を見ながら進めたいときに使います。

## ページの翻訳

今見ているページだけを翻訳します。

長い文書を少しずつ進めたいときに便利です。

## 選択複数行を1テーブルとして再抽出

選択した複数行を、表としてまとめ直す機能です。

表の読み順が崩れたときの修正に使います。

## 辞書登録

単語や用語を辞書へ登録します。

固有名詞や専門用語をそろえたいときに使います。

## 選択文字列をマークアップ

選択した文字へハイライトや下線を付けます。

見返したい部分の目印として使えます。

## 目次の再生成

現在の見出し情報をもとに、目次を作り直します。

見出しの種別を変えたあとに使うと分かりやすくなります。

## シンボルフォント

シンボルフォントの置換設定画面を開きます。

記号や特殊文字が崩れている PDF を扱うときに役立ちます。

## シンボル置換

シンボルフォントの置換ルールを適用して、原文を作り直します。

特殊なフォントが原因で文字化けしたように見える場合に使います。
